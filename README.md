# Michele Forte - Personal Portfolio & Showcase

Questo repository contiene il sito web portfolio personale di **Michele Forte** (MiFo Labs), progettato per il deploy immediato su **Render** come Static Site.

## 🚀 Caratteristiche Tecniche
- **Design Moderno**: Dark Mode con effetto Glassmorphism, sfondi dinamici e micro-interazioni.
- **Zero Dipendenze**: HTML5, CSS3 avanzato e Vanilla JS pronti all'uso senza bisogno di fare `npm install` o fasi di build complesse.
- **SEO & Lightweight**: Veloce da caricare e completamente responsive su tutti i dispositivi.

## 📦 Come fare il Deploy su Render
1. Carica questi file su un nuovo repository GitHub.
2. Vai su [Render Dashboard](https://dashboard.render.com/).
3. Clicca su **New +** -> **Static Site**.
4. Connetti il tuo repository GitHub.
5. Lascia i campi **Build Command** vuoti e imposta **Publish Directory** su `.`.
6. Clicca su **Create Static Site**.
